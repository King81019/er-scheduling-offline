# 空白排班工具（離線版）

下載單一 HTML，用瀏覽器開啟即可使用。無需安裝、登入或 Firebase。

## 下載與開啟

1. 到 [最新版下載](https://github.com/King81019/er-scheduling-offline/releases/latest)，下載附件 **er-scheduling-offline.html**。
2. 在電腦上雙擊下載的 HTML，以 Chrome、Edge、Firefox 或 Safari 開啟。
3. 輸入人員名單（每行一位），按「套用名單」。初次開啟的人員、班種及班表皆為空白。
4. 新增班種，設定名稱、開始／結束時間及每日需求人數。
5. 選月份，勾選個人可上班種，在預假表點選想休的日期。需要時設定每日需求例外。
6. 按「自動排班」，檢查缺額和提示，也可在班表下拉選單手動調整。或按「建立空白班表」完全手動填寫。

GitHub 的檔案預覽只會顯示程式碼，請下載 Releases 裡的 HTML 附件後開啟。手機瀏覽器對本機 HTML 開啟方式的支援不同，建議使用電腦。

## 儲存、備份與分享

- 每次變更會自動存到此瀏覽器的本機儲存空間；不能儲存時，頁面會顯示提醒，仍可匯出備份。
- **請定期按「匯出備份」**：JSON 包含全部人員、班種、各月預假、需求及班表。
- 更換電腦、瀏覽器、移動／重新命名 HTML、使用私密模式或清除瀏覽資料時，本機資料可能不會保留。請先備份，再用「匯入備份」還原。
- 匯入備份會取代全部資料，操作前會詢問確認。無效備份會拒絕匯入。
- HTML 本身始終是空白工具；把 HTML 傳給別人不會附帶你填的資料。若要一起分享資料，另傳 JSON 備份。
- CSV 只供查看班表，不能用來還原。列印功能可使用瀏覽器的「另存為 PDF」。
- 單檔完全內嵌程式及樣式，沒有 CDN、雲端同步、分析追蹤或任何網路請求。
- 這是單人本機工具，沒有多人即時共編、登入、雲端發布、值班費或寄信功能。請避免同時用多個分頁編輯同一份資料。

## 排班範圍

沿用通用排班引擎，考量一人一天一班、整日預假、可上班種、公平分配、11 小時班間休息和最多連續工作 5 天。引擎對超過每日 10 小時的部分計算延長工時，以每人每月 46 小時作為上限。人力不足時留下缺額，不會硬塞人員。

手動調整可超出這些限制，畫面會重新提示預假衝突、未勾選班種、班間休息、連班、需求不足／超額，以及 14／28 天窗口內未排班日不足。取消全部可上班種的人員不參與自動排班。

此版本逐月獨立計算，沒有串接前後月班表；不區分各類法定假別，也沒有完整計算實際加班或適用法規。班表及相關提示仍需由排班者依單位制度、跨月銜接與適用規範審核。

## 原始碼與建置

`er-scheduling-offline.html` 是可直接使用的完整成品。`src/` 包含介面原始碼，`roster.ts` 是建置時使用的排班引擎，`build.mjs` 將兩者組合成單一 HTML。

```sh
npm install
npm run build
npm test
```

建置需要 Node.js 20 以上及 TypeScript；一般使用者只需下載 HTML，不需執行上述指令。
